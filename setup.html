Setup

1 · Widget (Scriptable)

  1. Install Scriptable from the App Store.
  2. Tap Copy widget script below. Your key is already filled in.
  3. In Scriptable tap +, paste, name it Habits, tap Done.
  4. Long-press the Home Screen › + › Scriptable › pick Medium or Large (6×2 grid) or Small (4 rings) › Add Widget.
  5. Long-press the widget › Edit Widget › Script: Habits. When Interacting: Run Script isn't needed — each ring opens its own link.
  6. Optional Parameter: water,run,stretch to choose habits, or style=bold;bg=#1c1c1e.

2 · One-tap Shortcuts

  1. Open Shortcuts › + › Add Action › Get Contents of URL.
  2. URL: tap Copy URL and paste.
  3. Tap the arrow › Method POST. Headers: add apikey = (Copy apikey) and Content-Type = application/json.
  4. Request Body: JSON. Add Text fields k = (Copy key), h = habit id (e.g. water), src = shortcut.
  5. Optional: add Show Notification “Logged”. Name it Log Water.
  6. Share › Add to Home Screen, pick an icon/color. Clear the name for an icon-only look.
  7. Duplicate the shortcut for each habit and change h.

Habit ids: . Add action = undo to remove the last log. Tapping a ring in the widget opens ?log=<id> instead.
